# AJ Shaw Photography homepage

This homepage supplies the site name and camera favicon for the hostname
`ajshaw0327-sketch.github.io`, including its photography portfolio subdirectory.
Google Search reads favicons from the hostname homepage, not individual project
subdirectories. The existing portfolio remains at:

https://ajshaw0327-sketch.github.io/aj-shaw-photography/

The favicon is an exact copy of the portfolio tab icon. See
`favicon-LICENSE.txt` for its CC0 origin. Google decides whether and when to
show the icon after recrawling this homepage.

GitHub Pages publishes from the `main` branch, repository root.
